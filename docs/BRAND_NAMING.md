# Hierarquia de nomenclatura

**Orbiqo** é o nome visível do produto e do protocolo de símbolos. A interface deve falar de símbolos Orbiqo, protocolo Orbiqo e versões de Draft do protocolo.

**RadialCode** é o nome técnico da implementação de referência local. Ele aparece apenas em atribuição, metadados de artefato, diagnóstico técnico e documentação de implementação. Não deve ser apresentado como uma tecnologia externa da qual Orbiqo dependa nem como o nome do protocolo público.

| Contexto | Forma preferida |
| --- | --- |
| Hero e navegação | Orbiqo / símbolos Orbiqo |
| Explicação de produto | Protocolo Orbiqo Draft 0.6 |
| Implementação técnica | Implementação de referência RadialCode |
| Rodapé | Protocolo Orbiqo · referência RadialCode |
| Atribuição de artefato | Built with the RadialCode reference implementation |
