# RadialCode attribution policy

RadialCode is distributed under the **Apache License 2.0**. The legal terms are defined exclusively by [`LICENSE`](LICENSE), and redistributed source distributions must retain the applicable copyright, license and notice information.

The project requests the following human-readable credit whenever practical:

> Built with RadialCode — an open radial 2D code project.

For applications and services, place the credit in documentation, an acknowledgements screen or product credits. For libraries and redistributed source code, retain `LICENSE`, `NOTICE` and this file. For generated SVG files, the reference renderer embeds a metadata element identifying RadialCode as the generator; removing this metadata is not required by the license, but retaining it is strongly encouraged.

This attribution policy does not require visible branding inside the radial symbol and does not make a logo part of the decoding process.
